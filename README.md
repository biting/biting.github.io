# Ting Bi's Academic Homepage

Source code for https://biting.github.io/ (Bilingual EN / 中文, Light / Dark mode, zero-build static site).

## Quick Deployment

1. Unzip and place your portrait photo at `assets/avatar.jpg`.
2. Push to `https://github.com/biting/biting.github.io.git` (`main` branch).
3. Enable GitHub Pages in **Settings -> Pages** (`Deploy from a branch`, `main`, `/ (root)`).
